# Not — Offline-First PWA Notes

Лаконичное и быстрое PWA-приложение для заметок, созданное с упором на локальную работу (Offline-First) и облачную синхронизацию. 

> **Клонировать репозиторий и собирать проект НЕ нужно!** Всё уже собрано и задеплоено. Приложение полностью готово к работе прямо в браузере с любого устройства (ПК, смартфон, планшет). Можно установить его как нативное PWA-приложение на рабочий стол или экран «Домой».

---

## Основные приколы

- **Ready to Use:** Работает из коробки по ссылке [not.mozgi.workers.dev](https://not.mozgi.workers.dev).
- **Offline-First:** Заметки создаются и редактируются мгновенно. Если нет интернета — данные сохраняются локально на вашем устройстве.
- **Cloud Sync:** Автоматическая синхронизация заметок с базой данных Supabase при появлении сети.
- **PWA Поддержка:** Можно установить на iOS / Android / Desktop и пользоваться даже без подключения к сети.
- **CI/CD:** Автоматическая сборка и деплой через Cloudflare при каждом `git push`.

---

##  Стек it

- **Frontend:** React + Vite
- **UI & Styling:** Tailwind CSS
- **Local Storage (Offline):** Dexie.js (IndexedDB)
- **Database & Sync:** Supabase (PostgreSQL)
- **Hosting & CI/CD:** Cloudflare
